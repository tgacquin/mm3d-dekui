# Known issues

- Camera behavior may have issues, including unexpected zoom or positioning.
- Sheikah Stones tutorials have not been updated for a single screen
- Europe (PAL) dumps are supported as an experimental option (tested with a French dump; the USA path is unchanged). Classic dialogue storage (Classic Saving prompts, Classic Double Time) only exists for USA text, so Europe keeps its native messages.
- Europe: the single-screen HUD replaces the language-specific layouts (`layout/EU_*`) with English ones, so a few menu labels (Items, Map, Change tab, Choose, Return, Equip to I/II) are shown in English regardless of the game language.
