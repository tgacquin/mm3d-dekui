MM3D controls/text audit — 22 October 2026

Status: optional stick-click layout implemented; default off.

Controls (Controls > Use stick-click controls)
- ZL: assign/use Item I; ZR: assign/use Item II.
- Right-stick click: existing contextual first-person/pictograph action.
- Left-stick click: minimap visibility toggle with the existing camera-zoom cue.
- Off restores Restoration controls and instructions. Existing X/Y, D-pad,
  Start/Select and menu navigation keep their mappings.
- Existing SDL controller profiles gain missing click bindings only. Explicit
  custom bindings remain unchanged. Keyboard defaults are 3 (left) and 4 (right).
- Auxiliary host bindings do not change the emulated 3DS HID/IR/NS bit ranges.
- With the option enabled, HUD I/II exchange physical placements as complete
  groups (label, item, count and background). Player offsets and all editor
  presets are looked up through the same reversible mapping. Existing layout
  files and inventory saves are not rewritten. Off uses the original mapping.
- User correction: ZL / Item I comes first in the prompt row, ZR / Item II
  second. Earlier testing used the reverse assignment; this supersedes it.

Language and prompt changes
- English, French and Spanish each have optional variants for 0043 (camera),
  026b (item assignment/use), and 1d18 (minimap). Other message IDs retain their
  existing single-screen wording. The complete legacy inventory follows below.
- Runtime accepts original, legacy and stick-layout hashes, and can switch
  in either direction on message open. Disabling single-screen instructions
  restores original text. No native GMSG assets are modified.
- Camera/minimap instructions explicitly say to press the right/left stick;
  the movement-stick glyph is not repurposed to mean a click.
- Prompts use "ZL - Equip to I" and "ZR - Equip to II" (localized labels),
  with exactly one native-font space on either side of the dash. Off retains
  the ZR + X/Y icon prompts. Both vertical/horizontal layouts are supported.
- HUD/editor help agrees with the selected layout.

Verification
- Reviewed all 18 authored English edits / 12 message IDs and 20 custom prompt
  labels. French and Spanish each have 20 authored edits over the same 12 IDs.
- Scanned all 6,152 original English entries for relevant touchscreen/control
  instructions. Ordinary narrative uses of touch/tap are left unchanged.
- Generator checks native allocation capacity, control round trips and message
  flow. Runtime tests verify whole-file isolation, both layout transitions,
  single-screen text off/on, idempotence, all three languages, and refusal to
  overwrite unrecognized/custom text.
- Prompt fixtures check localized glyph records, exact separators, horizontal
  bounds and restoration of guest scratch memory.
- Input fixtures check native fallback, press/hold/release, short clicks,
  held-input suppression on enable, menu/transition gating, minimap sound and
  native-code signatures. Controller fixtures cover click bindings/events.

Other existing English changes reviewed for relevance
- Classic owl save/resume message 0c01: save/quit/resume wording and Yes/No choices; no affected trigger/stick instruction.
- Classic Double Time 1b8a: five time-destination questions; no affected instruction. 1b94 keeps the existing final-night failure wording.
- Price text specifications: amount changes, shortened shop prose and one rewrite; no ZL/ZR or stick-click mapping. No changes required for this option.
- Vanilla item acquisition messages often mention X/Y. Those remain valid with direct extra-item triggers; expanding them to enumerate every slot would be an additional wording change, not required to correct the proposed remap.
- Notebook, map, file-select and ocarina prompts retain their current labels/actions unless their actual bindings change. Do not apply OOT-specific Start/Select behavior to MM.
